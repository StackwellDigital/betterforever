# Better Forever website

The chosen design is the original ("Classic") style, now at the site root. The other four demo styles and the picker were removed; they are preserved in git history at commit `8bc98b5` (run `git checkout 8bc98b5` to see them).

Static rebuild of the Better Forever (Langley, BC) site. Plain HTML, CSS and a little vanilla JS. No framework, no build step on the host. Brand colours, fonts, copy and contact details come from the client's existing preview site.

## Layout

```
site/            <- deploy this folder (CF Pages "build output directory")
  index.html, pain/, perform/, young-forever/, team/, contact/, book/, 404.html
  css/styles.css          brand tokens live in :root at the top
  js/config.js            Jane App URLs + form endpoint (the only file to edit for booking)
  js/main.js              nav, carousel, Jane link wiring, forms
  img/ fonts/             logo, self-hosted Montserrat + Open Sans (variable woff2)
  _headers                security headers + caching (Cloudflare Pages format)
tools/build.py   <- generates every page. Page copy, header and footer live in tools/classic.py; styles in site/css/classic.css
```

Pages are generated, so **edit `tools/build.py` and re-run it, not the HTML**:

```
python3 tools/build.py
```

Needs only Python 3. It rewrites everything under `site/` except css, js, img, fonts and `_headers`.

## Before this can be used for real

1. **Photos.** Two image files were not copied over. Save them from the existing preview into `site/img/` using these exact names:
   - `joel-and-clients.avif` (hero background; without it the hero is a plain green gradient)
   - `joel.avif` (Joel's portrait on /team; without it his card shows initials like the others)
2. **Jane App.** Open `site/js/config.js` and paste the clinic's Jane URL into `jane.general`, plus per-practitioner URLs if they have them. Until then every Book Now button lands on the on-site `/book/` page so nothing is a dead link.
3. **Inquiry forms.** `inquiryEndpoint` is `/api/inquiry` (Pages Function in `functions/api/inquiry.js`, sends via Resend from forms@betterforever.ca to info@betterforever.ca). Needs the `RESEND_API_KEY` secret (send only key) in Pages env vars. No key set means the form shows the error message with the phone and email fallback.
4. **Go live.** In `tools/build.py` set `DEMO = False` and re-run it. While `DEMO = True` every page has `noindex` and `robots.txt` blocks all crawlers, so the demo cannot get indexed. Going live also writes `sitemap.xml` using `SITE_URL`.
5. **Hours** were "to be confirmed" on the client's preview, so they are left off. Add them (and `openingHoursSpecification` in the JSON-LD) once known.
6. The preview's footer social icons pointed at `#`. They are omitted here; add real links when the client has them.

## Compliance flag for the client

The copy includes outcome claims, a money-back guarantee, success-rate figures, and named client testimonials. Regulated health professionals in BC (naturopathic doctors, chiropractors, kinesiologists) are bound by their college's advertising standards, which restrict testimonials and guarantees. The copy is carried over unchanged from the client's own draft, but they should confirm it with their colleges before launch.

## Blog (self serve posts)

The center writes posts at `/admin/`. No GitHub, no build. Posts live in Cloudflare D1, pictures in R2, and
`/blog/` plus `/blog/<slug>/` are rendered by Pages Functions using the same header and footer as the static pages.

- `functions/blog/*` public pages, `functions/img/blog/*` images, `functions/sitemap.xml.js` sitemap with posts
- `functions/admin/_middleware.js` and `functions/api/admin/*` the editor API, both need a Cloudflare Access login
- `site/admin/` the editor page. `migrations/0001_blog.sql` the table. `wrangler.toml` declares the D1 and R2 bindings
- `functions/_lib/shell.js` is generated by `python3 tools/build.py` (header, footer, CSP). Never edit it by hand. Commit it with the HTML

One time setup (Cloudflare). The editor is used at `https://betterforever.pages.dev/admin/`, not on www, because
Access can only protect hostnames on a Cloudflare zone and betterforever.ca DNS is at GoDaddy. The blog itself is public on www.
1. Pages, betterforever, Settings, General, Access policy, Enable. That creates an Access app for `*.betterforever.pages.dev`
   (branch previews). In Zero Trust, Access controls, Applications, open that app and add a destination
   `betterforever.pages.dev` with paths `admin*` and `api/admin*`.
   Policy: Allow, emails Eilah (main), Adam, and Dick if wanted. Login method: One time PIN.
2. Copy the app's Audience (AUD) tag. Pages, Settings, Variables and Secrets, add as Secrets (Production and Preview):
   `ACCESS_TEAM_DOMAIN` (like `yourteam.cloudflareaccess.com`) and `ACCESS_AUD`. Retry the deployment afterwards.
   Until both exist every admin request is refused (fails closed). On www `/admin/` always returns 403, by design.

Local: put `DEV_AUTH_EMAIL=you@example.com` in `.dev.vars` (gitignored, only honored on localhost),
`wrangler d1 execute betterforever-blog --local --file migrations/0001_blog.sql`, then `wrangler pages dev site`.

Notes: previews share the production D1 and R2, so keep test posts as drafts and delete them. D1 Time Travel gives
30 day restore. Images are resized to 1600 px JPEG in the browser (drops EXIF). Posts dated in the future go live that day.
